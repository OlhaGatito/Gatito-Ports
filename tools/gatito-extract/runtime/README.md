# Gatito XZ Runtime\n\nO `xz` normal pode depender de `liblzma.so`. O XZ Utils também documenta `xzdec` e `lzmadec` como decodificadores menores; eles podem ser construídos com `liblzma` estática. citeturn2search0turn2search2\n\nOrdem usada pelo helper: `xz -dc` → `xzdec` → `lzmadec` → `unlzma -c` → `lzma -dc` → `busybox xz -dc`.\n\nCada rota precisa produzir uma saída não vazia. O helper não instala pacotes nem modifica o sistema.\n\nUse o helper em uma rota de recipe como `sh {recipe_dir}/runtime/gatito-xz.sh {stage}/entrada.xz {stage}/saida`.\n\nA engine do Gatito também suporta `fallbacks` em hooks: a rota principal falha → UI registra o erro → próxima rota é tentada → checkpoint valida → só então a próxima etapa é liberada.
